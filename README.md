# bigtoemusic.com

Static website for BigToe Music, served by GitHub Pages.

- Pages: `index.html`, `faq.html`, `contact.html`, `confirmed.html` (Kit's confirmation email lands here)
- Shared: `styles.css`, `main.js`, `assets/`
- Signups go to Kit (form 9997801); the contact form goes to Web3Forms → info@bigtoemusic.com.
- After editing `styles.css` or `main.js`, bump the `?v=N` tag in every HTML page so browsers fetch the new copy.

Preview locally: `python3 -m http.server 8765` in this folder, then open http://localhost:8765
