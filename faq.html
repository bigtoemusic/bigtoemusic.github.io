What is Big Toe?

Big Toe is a MIDI foot controller built to integrate with your MIDI enabled software and hardware. You will need an audio interface to connect with your software effects.

How do the Big Toe’s pedals work?

RFID (Radio Frequency Identification) tags power the pedals. Each tag represents a pedal.

When setting up pedals, you associate tags with MIDI events that will be sent to your effects software or hardware whenever that tag is read.

How do I set up my pedals?

Connect your Big Toe to your computer/tablet/phone using WiFi. It will show up as a network device just like your home router. Connect to it. Start a web browser and type in bigtoe.local to start the Big Toe monitor.

The Big Toe monitor is where you add, modify and delete your pedal definitions as well as monitor your pedals live. It can also be used to trigger most midi events.

What is the WiFi password?

The default WiFi password is 1234567890. You can change this from the menu.

What are all the characters after “BigToe-“ in the device name?

The default name of your device is “BigToe-“ followed by several characters which make up the MAC address of your device. The MAC address uniquely identifies your device on the network. Use the menu option to change this to something meaningful.

How do I connect Big Toe to my MIDI software?

On a Mac, use Apple’s built in Audio Midi Setup Utility. Open the Bluetooth window and connect to your device. Big Toe’s LED will turn blue when connected.

On iOS and iPadOS devices you can use any number of 3rd party utilities to connect such as Conji. Some apps such as LoopyPro have this connection built in to their app.

How do I connect Big Toe to MIDI hardware?

Use a Bluetooth MIDI Adapter such as WIDI Master. Big Toe will automatically connect as a Peripheral device.

Where do I set up my pedals?

Once you have connected your web browser to your BigToe, open a browser window and type in the url bigtoe.local.

The Big Toe screen willl appear and you can start adding and editing your pedals.

Pedals are added to 'pads' reflecting your physical pads. Each pad on the screen can hold 4 pedals just as each physical pedal can comfortably hold 4 RFID tags.

What are the different pedal modes?

Pedals are defined from the Edit window when you Add a new pedal or Update an existing one and operate in one of the following modes:

Footswitch: This is the classic stomp box type pedal. Big Toe will automatically toggle values between 127 and 0 to trigger ON and OFF actions for your effects.

Momentary: Upon tapping a tag defined as momentary pedal, Big Toe will send out a value of 127 and it will send out a value of 0 when you have moved the RFID reader away from the tag ‘releasing’ the trigger. If the momentary event is not the first event for that pedal, the OFF event will be fired right away.

Expression: Big Toe has a unique way of implementing expression or continuous control. A typical setup involves setting up a few pedals to implement expression pedal functions.

Set one pedal with a specific CC number and a value indicating where on the scale from 0 to 127 your 'dial' is to be set. This may be your baseline value.

Set a second pedal with the same CC number and value. Set a value for +/-, let's say Increase, to increment that value when triggered and the corresponding value to Bump by.

Set a third pedal with the same CC number and value. Add a +/- value, this time to Decrease that value when triggered and an amount to decrease by.

Expression pedals defined in this way with the same CC number will show up on your monitor as 1 pedal.

Can I change the layout of the pedals on the pads?

Yes. Using the Pad Layout menu option, you can set the number of pads on a given row on the screen and the order of those pads.

Can I change the order of the pedals on the page?

Yes, You can rearrange the order of pedals shown on your browser.

Press/touch and hold the pedal, drag it on top of the pedal location you where would like it to be and release. All other pedals will move right. If you drop between any pedal location, you pedal will move to the end. You can drag within a pad and from pad to pad.

What are Groups?

When you set a Group name for Footswitch pedals, Big Toe will ensure only one pedal in the Group with that name is ON at any one time. This is useful for switching between effects of a similar type, such as distortions, reverbs, amp sims, or switching between channels.

Let's say for example, you have 3 pedals defined, Overdrive, Distortion and Fuzz, that have all been given the same group name 'DRIVES'.

Tapping Overdrive will turn that pedal on and fire the event. Tapping Fuzz, will turn the Fuzz on and fire that event and turn off the Overdrive pedal.
